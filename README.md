# ColorSprout support website

Static English support and privacy pages for the iOS app. No JavaScript, external fonts, analytics, or build dependencies.

## Publish with GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, **main**, **/(root)**, then Save. Keep HTTPS enabled.

- Home: https://howardchenhaoyang.github.io/colorsprout-site/
- Privacy Policy URL: https://howardchenhaoyang.github.io/colorsprout-site/privacy.html
- Support URL: https://howardchenhaoyang.github.io/colorsprout-site/support.html

## Maintain

Edit the HTML and styles.css, then push to main. Keep the privacy policy aligned with the actual shipping app and support practices. Change the effective date when the policy changes. The website is public; do not commit app source, credentials, or private user correspondence.

Preview locally with `python3 -m http.server 8080` from this directory.
